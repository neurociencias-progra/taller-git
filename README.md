# 🏋️ El taller de git

Este repositorio es el **gimnasio** del curso: aquí se practica git y GitHub sin miedo a
romper nada, porque no hay nada que romper. Cada quien entrena en **su propia copia**.

## Cómo se usa

1. Arriba a la derecha: **Use this template** → *Create a new repository* → nómbralo
   **`taller`** → **Public** → *Create repository*.
2. Clona **tu** copia desde VSCode: `Ctrl+Shift+P` → **`Git: Clone`** → pega la URL de TU
   repo → elige una carpeta de tu home **sin acentos ni espacios**.
3. Sigue la guía: [`docs/practica-git.md`](docs/practica-git.md) — o su gemelo en
   cuaderno, [`practica-git.ipynb`](practica-git.ipynb), si la terminal se pone necia.
