# 📋 Los issues por abrir

GitHub **no copia los issues** de una plantilla: cada quien abre los suyos. En tu
repositorio → pestaña **Issues** → **New issue** → copia título y cuerpo → *Submit*.
Ábrelos **en este orden**, para que los números coincidan con la guía.

---

**Issue #1 — título:** `Preséntate al equipo`

> Crea el archivo `equipo/tu-nombre.md` (con TU nombre, en minúsculas y con guiones:
> `ana-lopez.md`) con tres líneas: quién eres, un dato curioso y qué esperas del curso.
> Hay un ejemplo en la carpeta. Se cierra con un commit cuyo mensaje empiece con
> `Closes #1:`.

---

**Issue #2 — título:** `El README miente`

> En el README hay un dato de neurociencias **falso**. Encuéntralo, corrígelo y cierra
> este issue con un commit `Closes #2:` que diga qué corregiste.

---

**Issue #3 — título:** `Inaugura la bitácora`

> Agrega tu línea a `bitacora.md` con el formato que ahí se indica. Se cierra con
> `Closes #3:`. *(Este es el de sobremesa: si no da tiempo en clase, va de práctica en
> casa — o inténtalo desde una rama, si te sientes valiente.)*
